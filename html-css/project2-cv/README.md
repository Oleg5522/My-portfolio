# Personal CV Website

A multi-page personal website presenting a curriculum vitae, built as a second HTML/CSS project.

## What it does

- Presents a personal biography across multiple connected pages
- Includes a navigation menu on every page linking to: Preambule, Main, and Contacts
- The Main section is split into four chapters, each on its own page, with links to continue reading
- Contacts page includes an email link

## Pages

| File | Content |
|------|---------|
| `2ProjectPreambule.html` | Introduction and background |
| `2ProjectMain.html` | Chapter 1 — Beginning of professional life |
| `2ProjectMain1.html` | Chapter 2 — A turning point |
| `2ProjectMain2.html` | Chapter 3 — Adventures in Africa |
| `2ProjectMain3.html` | Chapter 4 — Post-African period |
| `2ProjectMain4.html` | Chapter 5 — Dramatic unexpected turn |
| `2ProjectContacts.html` | Contact information |

## Technologies

- HTML5
- CSS3 (two stylesheets: `2project.css` and `Project2.css`)

## How to open

Open `2ProjectPreambule.html` in any browser and navigate using the menu. No server required.

## Notes

This is a course project completed as part of an HTML & CSS fundamentals course.
