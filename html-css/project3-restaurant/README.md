# The Last Supper — Restaurant Website (Group Project)

A multi-page restaurant website built as a group project (3 people) as part of an HTML & CSS course.

## About the project

This was a collaborative project. The concept — a restaurant with a funeral theme — was chosen by the group.

## My contribution

I was responsible for all customer-facing forms:

| File | Description |
|------|-------------|
| `button_all_Oleg.html` | Main navigation page with links to all forms |
| `Form_registration_Oleg.html` | Customer registration form |
| `Form_order_Oleg.html` | Food order form |
| `Form_address_Oleg.html` | Address / location lookup form |
| `Form_review_Oleg.html` | Customer feedback form |
| `form button design Oleg.css` | Styling for all buttons and forms |

## Technologies

- HTML5
- CSS3 (Flexbox, animations)

## How to open

Open `button_all_Oleg.html` in any browser to access all forms. No server required.

My teammates handled the landing page, menu, and overall site design. The project contains 42 files in total.
