# Homemade Chocolate Recipe — Personal Page

A personal webpage about making homemade chocolate from scratch, built as a first HTML/CSS project.

## What it does

- Describes a personal homemade chocolate recipe with ingredients and preparation steps
- Includes images of the finished product
- Uses external links to show what less familiar ingredients look like
- Styled with a custom CSS file using Google Fonts

## Technologies

- HTML5
- CSS3
- Google Fonts (Playwrite VN)

## How to open

Open `index_project1.html` directly in any browser. No server required.

> Note: two images (`My chocolate bar on the scale.jpg` and `My chocolate range.jpg`) are local files and need to be in the same folder as the HTML file to display correctly.
