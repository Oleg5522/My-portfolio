# Rock || Paper || Scissors

A browser-based Rock, Paper, Scissors game built with vanilla JavaScript, HTML, and CSS.

## What it does

- Presents three buttons to choose from: Rock, Paper, or Scissors
- Randomly generates the computer's choice
- Displays the result with images of both choices (yours and the computer's)
- Announces whether you won, lost, or drew
- Lets you play again without reloading the page

## Technologies

- HTML5
- CSS3 (Flexbox)
- JavaScript (ES6+, DOM manipulation, event listeners)

## How to open

Open `index.html` in any browser. No installation or server required.

## Project structure

| File | Description |
|------|-------------|
| `index.html` | Game layout and structure |
| `style.css` | Styling and layout |
| `index.js` | Game logic |

## Notes

This is a final project completed as part of a JavaScript fundamentals course.
The game uses real photos from Pexels to display each choice.
